📘 JavaScript – Very Short Notes


Data Types: Number, String, Boolean, Undefined, Null, Object, Symbol, BigInt


Variable: Stores data → let x = 10;


let vs const:


let → can change


const → cannot change


Strings: Text in quotes, immutable


Concatenation: Join strings → + or template literals `${}`


console.log(): Prints output


typeof: Checks data type


Bracket Notation: Access characters → str[0]


Escape: \n, \", \\


Useful Methods:


indexOf() → position


includes() → true/false


slice() → extract


replace() → change text


repeat() → repeat text

Case Methods: toUpperCase(), toLowerCase()


User Input: prompt()


👉 Tip: Use const by default, let when value changes.
